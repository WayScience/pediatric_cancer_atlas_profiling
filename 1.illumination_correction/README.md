# Illumination correction

In this module, we create LoadData CSVs to use in CellProfiler and generate illumination correction functions per channel to apply in the next pipeline.
We also extract whole image quality metrics per plate as CSVs to use in the next module to determine thresholds for determining good versus poor quality images.

It took approximately **two hours** to generate IC functions, across 6 plates (Round 1), as `npy` files and extract spreadsheets of the image quality control measurements.
We are using a Linux-based machine running Pop_OS! LTS 22.04 with an AMD Ryzen 7 3700X 8-Core Processor with 16 CPUs and 125 GB of MEM.

## Create LoadData CSVs and perform IC

Before running the bash script, we will need to create the LoadData CSVs using [the Jupyter notebook](./0.create_loaddata_csvs.ipynb).
It only takes about **30 seconds** to run just this notebook.
There is an error that occurs when processing via the Python script, which does not occur if using the notebook.
See [issue #34](https://github.com/broadinstitute/pe2loaddata/issues/34) for further details.

Once you run the create LoadData CSVs using [the first notebook](./0.create_loaddata_csvs.ipynb), you can run the IC CellProfiler pipeline to extract image quality metrics and IC functions using the command below:

```bash
# Make sure you are in the 1.illumination_correction directory
source loaddata_and_illum.sh
```

Both notebooks have the round of data to process (`batch_name`, for example `Round_1_data`) set near the top.
The first notebook also reads the raw images from `index_directory`, an absolute path on the lab machine that you will need to point to where you downloaded the plates (see the [download data module](../0.download_data/)).
Set both before running them.

## Image quality control (optional)

The quality control thresholds were developed on Round 1 (the 6 plates in [`img_quality_control/whole_img_qc_output/`](./img_quality_control/whole_img_qc_output/)) and are applied in the next module to flag and skip poor quality images.
To update them, uncomment the image quality section of `loaddata_and_illum.sh`, or run the two notebooks in `img_quality_control/` in order.
The evaluation notebook (`1.evaluate_qc.ipynb`) does not use CellProfiler: it needs pandas, NumPy, SciPy, matplotlib, and seaborn.

The thresholds that [`analysis.cppipe`](../2.feature_extraction/analysis.cppipe) uses (for each of the five fluorescence channels; an image set is skipped if any channel is flagged) are:

| Problem                 | CellProfiler metric             | Flagged when                       |
| :---------------------- | :------------------------------ | :--------------------------------- |
| Out of focus            | `ImageQuality_PowerLogLogSlope` | below `-2.7977` or above `-1.1262` |
| Smudges, oversaturation | `ImageQuality_PercentMaximal`   | above `4.2753`                     |
